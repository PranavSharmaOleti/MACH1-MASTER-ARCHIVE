Requirements Framework & Gap Analysis
for the 2035 EV Platform Proposal

Defines what each digital-layer pillar must specify, maps data flows and AI functions, then audits the existing proposal and Suzuki Connect against these requirements.

5 Pillars Analyzed Ola Electric Case · UN R156 · ISO 24089 Status: Gap Analysis
Framing note: The Ola Electric 2021–22 failure is the baseline for every requirement below — 80,000 complaints/month, sensor faults invisible until breakdown, big-bang software pushes with no rollback, and a rider-facing "black box." A credible proposal must either solve each of those failure modes explicitly, or acknowledge the gap. Generic features without data flows and decision logic are insufficient for a proposal at this level.

PART 3

Priority Additions for Proposal Readiness

Items are grouped by urgency. Red = proposal is not credible without it. Amber = gaps a sophisticated evaluator will probe. Blue = differentiators that strengthen the proposal.

CRITICAL · FLEET MGMT

Define Fleet Operator Dashboard Screens

The proposal has no fleet-ops UI specification. Add: OTA cohort status view, fault severity heat-map across 500+ vehicles, predicted downtime calendar, and SoH distribution chart. Without this, the platform is indistinguishable from Suzuki Connect's single-owner model.

CRITICAL · REGULATORY

SUMS Audit Trail & DPDP Act 2023 Compliance

Cite UN R156 and ISO 24089 but then show what the audit log contains: update manifest, vehicle ID, rollout timestamp, rollback events, and sign-off chain. Add a data governance matrix specifying retention, consent, and third-party exclusions under India's DPDP Act 2023.

CRITICAL · TELEMATICS

GPS Hardware Revision — Explicit Mismatch Prevention

The Ola GPS story is the opening case study, but the solution mechanism is underspecified. Add: hardware revision logged per component in the fleet manifest; OTA compatibility matrix check blocks push if antenna HW revision is incompatible with new firmware. Name this as a specific risk-scorer feature.

CRITICAL · SAFETY

Offline Edge Inference Capability

Indian fleet routes include rural and low-connectivity corridors. Specify: which fault classifiers run on-edge without cloud connectivity, local data buffer duration (minimum 72h recommended), and sync priority queue when connectivity restores. A cloud-only AI layer is a single point of failure for this market.

IMPORTANT · FLEET MGMT

OTA Cohort Gate Criteria (not just "staged")

The proposal says cohorts are staged but never defines the expansion gate. Add: the specific metric (fault-rate per 1,000 km, rollback events per cohort), the threshold that unlocks the next cohort, the waiting period, and who approves expansion — automated or human sign-off.

IMPORTANT · DRIVER APP

Driver UX Offline Fallback & Language Support

Plain-language fault messages must work when connectivity is lost. Specify: local DTC-to-language lookup table on-device, audio/haptic alert if display is frozen (closing Ola's frozen-screen failure mode), and minimum regional language support (Hindi + Bengali/Tamil/Telugu for initial fleet regions).

IMPORTANT · FLEET MGMT

Maintenance Workflow Integration

A "12-day fault prediction" is only valuable if it triggers a workshop booking. Add: fleet dashboard → workshop scheduling integration, spare-parts pre-positioning signal from fault class output, and technician mobile view showing expected fault type before vehicle arrives.

IMPORTANT · FLEET MGMT

Battery Second-Life & RUL Management

A 2035 vehicle proposal with no battery lifecycle economics is incomplete. Add SoH replacement threshold (commonly 70–80%), RUL regression output to fleet dashboard, and how expired batteries are flagged for second-life (stationary storage) vs. recycling. This is a cost and sustainability differentiator.

DIFFERENTIATOR · AI LAYER

Model Drift Monitoring & Retraining Pipeline

Benchmarks cited (97% accuracy, ±12d prediction) are training-time metrics. Add: production performance monitoring cadence, drift detection trigger (e.g., false-positive rate rising >5%), retraining pipeline (batch vs. continuous), and whether per-vehicle fine-tuned models update automatically or require fleet-ops approval.

DIFFERENTIATOR · FLEET MGMT

Charging Infrastructure Integration

Bind the AI layer to the charging network: nearest compatible charger, real-time availability, smart charging schedule (off-peak + SoH-aware charge rate), and charging session data looped back into the BMS telemetry. This closes the energy management loop and is a strong fleet-operator selling point.

DIFFERENTIATOR · TELEMATICS

CNG Variant Sensor Specification

Clarify which CNG sensors are in scope (pressure, temp, injector duty cycle), whether CNN/LSTM models are shared with EV variants or require separate training data, and how dual-fuel variant telemetry is handled. A single vague line on "fuel-system sensors" is insufficient for a proposal covering India's mixed fleet reality.

DIFFERENTIATOR · AI LAYER

Telemetry Pipeline Infrastructure

Name the streaming protocol (MQTT preferred for low-bandwidth IoT), time-series database, edge compression ratio target, and what happens during extended offline periods. This transforms the data layer from a concept into a buildable architecture that procurement and engineering teams can evaluate.
